## Collections

### `docs`

- Quelle: `src/content/docs/<locale>/docs`
- Loader: `docsLoader()`
- Ausgabe: `/<locale>/docs/...`

### `blog`

- Quelle: `src/content/blog/<locale>`
- Loader: `glob()`
- Ausgabe: `/<locale>/blog/...`
