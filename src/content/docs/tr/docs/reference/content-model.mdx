## Koleksiyonlar

### `docs`

- Kaynak: `src/content/docs/<locale>/docs`
- Yukleyici: `docsLoader()`
- Cikti: `/<locale>/docs/...`

### `blog`

- Kaynak: `src/content/blog/<locale>`
- Yukleyici: `glob()`
- Cikti: `/<locale>/blog/...`
