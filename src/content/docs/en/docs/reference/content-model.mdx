## Collections

### `docs`

- Source: `src/content/docs/<locale>/docs`
- Loader: `docsLoader()`
- Output: `/<locale>/docs/...`

### `blog`

- Source: `src/content/blog/<locale>`
- Loader: `glob()`
- Output: `/<locale>/blog/...`
