## Why this structure?

This setup separates two concerns cleanly:

1. **Marketing and custom pages**
   Keep the existing header, footer, and SCSS shell through `src/layouts/Layout.astro`.
2. **Documentation and knowledge surfaces**
   Use `Starlight` for auto-generated sidebar navigation, Pagefind search, and markdown-first SEO output.
