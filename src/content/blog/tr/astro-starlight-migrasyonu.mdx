## Problem Tanimi

Tasarim bozulmadan framework degisikligi yapmak genellikle iki risk dogurur:

1. CSS cascade bozulur.
2. Crawl edilmesi gereken bilgi mimarisi yeniden yazilirken SEO sinyalleri zayiflar.

## Uygulanan Strateji

- Global SCSS aynen korundu.
- Layout HTML sinif isimleri yeniden kullanildi.
- Dokumantasyon Starlight tarafina tasindi.
- Blog Astro content collection ile tip-guvenli hale getirildi.

## Beklenen Kazanim

- Daha dusuk istemci JavaScript maliyeti
- Daha net docs bilgi mimarisi
- Daha iyi statik HTML ciktisi
- Daha kolay sitemap ve search entegrasyonu
