## Problem Statement

Changing frameworks without changing the design usually introduces two risks:

1. The CSS cascade can break.
2. SEO signals can weaken while rebuilding crawlable information architecture.

## Strategy Applied

- The global SCSS layer was preserved.
- Existing layout class names were reused.
- Documentation moved to Starlight.
- The blog was modeled with Astro content collections for type safety.

## Expected Gains

- Lower client-side JavaScript cost
- Clearer documentation information architecture
- Better static HTML output
- Easier sitemap and search integration
